Réalisations

Réseau d'entreprise virtualisé

Sous VMware et GNS3, j'ai construit un réseau séparant les postes utilisateurs, l'administration, Active Directory et un serveur web en DMZ. J'ai utiisé Open vSwitch pour les VLAN et pfSense pour contrôler les communications entre les zones.

AterlierRDV - Projet de groupe

Sur une application de prise de rendez-vous, nous avons intégré des contrôles dans Gitea pour repérer les secrets exposés, analyser le code Python et vérifier les dépendances. Nous avons aussi configuré le conteneur Docker pour que l'application s'exécute avec un utilisateur dédié.

Cloud familial auto-hébergé

J'ai créé et mis en service un cloud familial pour que mes proches disposent de leur propre espace de stockage ainsi que d'un stockage partagé pour se transmettre des documents en toute sécurité. Je m'occupe de l'hébergement et de l'administration du service.

Tamagotchi sur Raspberry Pi

J'ai fabriqué un Tamagotchi personnalisé autour d'un Raspberry Pi, avec des pièces imprimées en 3D. Ce projet réunit deux aspects de mon travail que j'aime associer: l'informatique et la création.

Serveurs Minecraft et mods

J'ai administré plusieurs serveurs Minecraft et je développe des mods pour personnaliser l'expérience de jeu.
